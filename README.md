# Airline Flights

A small Django project for viewing flights, flight details, and passengers. Django admin is available for managing airports, flights, and passengers.

## Setup

Activate a Python environment with Django installed, then run:

```bash
python manage.py migrate
python manage.py runserver
```

Open <http://127.0.0.1:8000/flights/> for the flight list or <http://127.0.0.1:8000/admin/> for Django admin.

## Tests

```bash
python manage.py test
```
